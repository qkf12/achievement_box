# 桌面小宠 DesktopPet

一只永远浮在屏幕最上层的小精灵：**左键一点，预设好的文字就进了剪贴板**。

没有依赖、不用安装、双击就能跑。

---

## 快速开始

双击 **`启动桌宠.bat`** 即可。

> 想要完全无黑框：双击 **`启动桌宠(无黑框).vbs`**

启动后，屏幕右侧会出现一个白色小圆球（大约两个鼠标指针那么大）。

---

## 功能对照

### 1. 始终显示在屏幕最上层

- 无边框、无标题栏，桌面上的一个小圆球
- 默认直径相当于 **两个 Windows 鼠标指针**（66 逻辑像素，在高分屏上自动按比例放大，不会变模糊）
- 每 1.5 秒自动重新置顶一次，不会被其他窗口压下去
- 圆球以外的区域是**完全透明且可以点击穿透**的，不会挡住桌面图标和窗口
- 可以按住左键拖到任意位置，位置会自动记住

### 2. 左键单击 → 复制预设内容

- 单击一次，预设内容立刻进入剪贴板
- 圆球会轻轻弹一下作为反馈，**不会弹出任何提示窗**（干净不打扰）
- 用的是 Windows 原生剪贴板接口，**关掉桌宠后剪贴板内容依然在**
- 按住拖动超过 4 像素算「移动」，不会误触发复制

### 3. 右键单击 → 设置面板

右键点一下圆球，弹出面板：

```
┌──────────────────────────────┐
│  桌面小宠              ✕     │
│  左键单击时复制下面这段内容    │
│  ┌────────────────────────┐  │
│  │ 在这里输入你的预设内容   │  │
│  │ （支持多行）            │  │
│  └────────────────────────┘  │
│  [  完成  ]  [ 仅保存 ]      │
│  ────────────────────────    │
│  形状：○ ▢ ▣ ★ ♥ ⬡ ◆         │
│  颜色：● ● ● ● ● ● ● ● ●     │
│  ────────────────────────    │
│  拖动可移动          退出桌宠 │
└──────────────────────────────┘
```

- **完成**：保存输入的内容 → 立即复制到剪贴板 → 面板消失
- **仅保存**：只保存，不复制
- **形状**：圆形（默认）· 圆角方块 · 方块 · 星星 · 爱心 · 六边形 · 菱形
- **颜色**：白色（默认）· 墨黑 · 蓝 · 青蓝 · 绿 · 黄 · 橙 · 红 · 粉 · 紫 · 棕 · 灰
- 选形状/颜色时主球会**实时预览**
- 面板里的内容、形状、颜色都会自动保存，下次启动保持不变

## 操作一览

| 操作 | 效果 |
| ---- | ---- |
| 左键单击 | 复制预设内容 |
| 左键按住拖动 | 移动位置 |
| 右键单击 | 打开 / 关闭设置面板 |
| 面板「完成」 | 保存 + 复制 + 关闭面板 |
| 面板「仅保存」 | 只保存，关闭面板 |
| 输入框内 `Ctrl + Enter` | 等价于点「完成」 |
| `Esc` | 关闭面板（不保存） |
| 面板「退出桌宠」 | 退出程序 |

## 进阶玩法

**开机自动启动**

1. 按 `Win + R`，输入 `shell:startup`，回车
2. 把 `启动桌宠(无黑框).vbs` 的快捷方式拖进打开的文件夹

**调整大小**

关闭桌宠，用记事本打开 `pet_config.json`，把 `"size": 66` 改成 50（更小）或 90（更大），保存后重新启动。

**恢复默认**

删除 `pet_config.json` 再启动即可。

## 常见问题

**Q：看不到小球？**
可能被全屏程序挡住了。全屏视频、全屏游戏、全屏幻灯片会自动盖住包括置顶窗口在内的所有窗口，这是 Windows 的系统行为。退出全屏（或按 `Win + D`）就能看到。

**Q：双击没反应？**
说明已经有一个桌宠在运行了（程序做了单实例保护，可防止出现一堆一模一样的小球）。找找屏幕右侧。

**Q：怎么退出？**
右键小球 → 右下角「退出桌宠」。

**Q：提示找不到 Python？**
需要安装 Python 3.8+（[python.org](https://www.python.org/downloads/)），安装时勾选 **Add Python to PATH**。

## 技术实现

- **纯 Python 标准库**：`tkinter` + `ctypes`，不需要 `pip install` 任何东西
- **透明悬浮球**：无边框窗口 + Windows 分层窗口色键（`-transparentcolor`），球外区域完全透明
- **球体质感**：Tk 的 Canvas 不支持渐变和抗锯齿，所以用「多层同心收缩 + 逐层调色 + 逐层偏移」模拟出柔和的受光球体
- **永久置顶**：定时调用 `SetWindowPos(HWND_TOPMOST)`
- **持久剪贴板**：直接调用 Win32 `OpenClipboard / SetClipboardData`，避免 Tk 剪贴板在程序退出后失效
- **高 DPI 适配**：通过 `SetProcessDpiAwareness(PROCESS_PER_MONITOR_DPI_AWARE)` + `winfo_fpixels("1i")` 换算，125% / 150% / 175% 缩放下大小都一致且清晰
